# Proton Mail compatibility

Lumenary Desk Mail can be configured for Proton Mail through Proton Mail Bridge.
Bridge runs locally and exposes Proton Mail through local IMAP/SMTP endpoints.

In the desktop app, choose:

- Provider: `Proton Mail via Bridge`
- IMAP server: `127.0.0.1`
- IMAP port: `1143`
- SMTP server: `127.0.0.1`
- SMTP port: `1025`

Use the mailbox username and password shown inside Proton Mail Bridge. Keep
Bridge running in the background while Lumenary Desk Mail is open.

Direct Proton Mail account passwords are not used by Lumenary Desk Mail.
